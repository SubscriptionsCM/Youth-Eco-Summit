Active release files, WordPress, private uploads and runtime configuration were excluded from replacement.

This demonstrates current workspace headroom; storage still needs capacity monitoring as real submissions accumulate.

The capacity correction required no application change. A separate saved-multiselect compatibility defect was subsequently reproduced and corrected in source; deployed in CI-validated release `740447fb5e3a75933fe861676e98a618c50c5591`, and the final step-by-step browser recheck passed. The regression failed before the change and passed afterward; independent review found no blockers. Staging the new release reused another 152,645,256 bytes of identical immutable build files. Pre-existing release archives remain intact.
