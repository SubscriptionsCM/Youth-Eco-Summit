# Unified records implementation plan

Goal: one user-facing forms/submissions collection, without origin-based menus, counters or selectors. Preserve source IDs, original dates, files, account boundaries, QC history and judging snapshots. No production invitations, assignments, business-data edits or migration to the postponed VPS.

1. Add a staff-only unified inbox service using the verified submission projection, including unknown historical form types without inventing their classification. Combine before sorting/pagination; search reference/person/school/form; filter canonical form type and school. Return bounded safe summaries and original authorized detail links. Keep existing low-level APIs for compatibility. Test mixed records, colliding UUIDs, unknown forms, filters/facets, original dates, privacy, role changes and unchanged originals.
2. Use this service in Forms & submissions. Redirect the former separate archive page into that collection, preserving filters. Show consistent dates, statuses and attachment counts. Remove source-separated dashboard totals, menus, report filters, school-record labels, detail-page explanations and Tools links. Keep sync limitations documented truthfully without recreating a source category.
3. Combine judge picker results and allow one atomic mixed-source assignment request. Keep the previous assignment API compatible. Test cross-source selection, stable pagination, same UUID in different namespaces, source verification, all-or-nothing rollback and assignment retries; no synthetic production assignments.
4. Combine participant-authorized records in the existing dashboard's All/Submitted views while keeping native draft continuation and original ownership checks. No account linking or grants inferred from names/emails.
5. Run focused tests/typecheck, review authorization, then desktop/tablet/mobile browser acceptance and the full release pipeline. Deploy via the existing guarded Hostinger process, verify live business reads, original-table/credential fingerprints and worker health. Keep private captures Git-ignored.
